## Filesystem operation hardening (2026-10-24)

Context: commit `1e0ed4f2` documents secure deployment and private vulnerability reporting; the preceding `4c08268c` introduces package path containment. Keep this follow-up separate from the package patch already confirmed by Yuan. Initial findings came from static analysis. Subsequent isolated Windows fixtures reproduced widget containment defects and verified the fixes; the maintainer confirmed valid widget export/import and Unicode wallpaper upload/display on Linux Vulkan. No anomalous requests were sent to the running backend. Follow [the security policy](../SECURITY.md) for suspected vulnerabilities.

Use protections scoped to each operation, reusing the package containment guard where appropriate. Do not globally prohibit writes to `programs/`: prevent unrelated operations from reaching it while preserving authorized program editing and code installation. Implement the following blocks in order, as separate, reviewable changes.

1. [x] **Widget confinement.** Guard Add/Save/Delete/Export and final WidgetImport copies; correct nested directory separators, module-file deletion, export metadata preservation and per-request import/export workspaces. Close ZIP resources on failures. Isolated Windows fixture: 72/72 checks; maintainer confirmed valid export/import on Linux Vulkan. This does not claim Linux containment or complete HTTP gateway regression coverage.

Isolated Windows fixture: 114/114 checks. The five legacy editor endpoints are now explicitly disabled at handler entry pending YoT support; internal Arduino engine/factory remain available. No live Arduino compile/upload acceptance is claimed.
3. [x] **Wallpaper uploads.** Validate multipart filename and explicit destination before writing; guard deletion too. MIG 1.3.12 fixes byte offsets for Unicode multipart filenames (68/68 isolated parser cases). Maintainer updated MIG, rebuilt Vulkan and confirmed Unicode wallpaper upload/display. No live byte-for-byte hash comparison or Linux containment regression is claimed.

[ ] **Isolated temporary workspaces (deferred by maintainer, 2026-10-24).** Replace shared temporary names/directories in import flows with an operation-owned workspace; limit cleanup to that workspace and prevent concurrent-operation collisions or cross-cleanup. Backup restoration spans multiple requests: retain operation state between steps rather than creating a different directory indiscriminately for each request. Widget import/export are already isolated; other import and backup flows remain pending.
